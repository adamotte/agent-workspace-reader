# atlas workspace

Everything the **atlas** agent reads and writes for `billing-service`.

| Folder     | Content                                 |
| ---------- | --------------------------------------- |
| `config/`  | Agent and MCP server configuration      |
| `memory/`  | What atlas remembers between runs       |
| `plans/`   | Plans a human approved                  |
| `reports/` | Deliverables, one per run               |
| `runs/`    | Logs, traces and tool calls of each run |
| `skills/`  | Skills atlas can load                   |
| `tools/`   | Scripts atlas runs                      |
